# うまくいかないとき

画面かターミナルに出たものから、することを探してください。

| 出るもの | すること |
|---|---|
| ターミナルに「Node.js 22 以上が要ります」 | Node.js を入れ直す |
| ターミナルに「必要な部品が入っていません」 | `npm install` を実行してから `npm start` |
| 観察の結果が「未確認」(`unverified`)で、理由に「Playwright の Chromium が見つかりません」。作る会話に「起動は確かめていません(未確認)」と出る | Studio のフォルダーで `npm run install:chromium` を実行する(約 200 MB をダウンロードする)。観察器は Playwright の Chromium だけを使い、利用者の Chrome や Edge は使わない。`npm install` で Playwright の版が変わったときも、入れ直す |
| 観察の結果が「未確認」で、理由に「Chromium を起動できませんでした」 | `npm run install:chromium` で入れ直す。続くときは、理由の括弧の中の文を確かめる |
| 観察の結果が「未確認」で、理由に「試作品のビルドを開けませんでした」 | 観察の間に作り直された。もう一度観察する |
| ターミナルに「ポート 4317 は使われています」 | 別のターミナルで Studio が動いていないか確かめる。他のアプリが使っているなら、番号を変えて起動する([configuration.md の「環境変数」](configuration.md#環境変数))。プレビュー用の 4318 は `STUDIO_PREVIEW_PORT` |
| 画面に「鍵がありません」「鍵が合いません」 | ターミナルに出た最新の URL(`#token=` を含む)を開き直す。起動し直すたびに鍵は変わる |
| 画面に「Studio のサーバーにつながりません」 | `npm start` のターミナルが開いたままか確かめる。止めたなら、もう一度 `npm start` |
| 右に「ビルドに失敗しました」 | 出ているファイルと行を直し、「作り直す」を押す。作る欄で直す依頼を送ってもよい。`app/ai.json` の誤りも、ここに項目の場所つきで出る |
| 作る欄に「送れませんでした: … 作業中です」 | 前の依頼が終わるか、「中断」を押すまで待つ。1 つの試作品で動く依頼は 1 つだけ |
| 作る欄に「時間の上限(10 分)を超えたので止めました」 | 依頼を小さく分けて送る |
| 作る欄に「Claude Code にログインしていないか…」 | ターミナルで `claude` を起動し、`/login` でログインしてから送り直す。Studio はログインの情報を扱わない |
| 作る欄の上の枠に「claude が見つかりません」「古すぎます」 | Claude Code を入れる、または `claude update` で更新して、Studio を起動し直す。別の場所にあるときは `STUDIO_CLAUDE_BIN`。Claude Code を使わずに試すときは `STUDIO_AGENT=fake` |
| 作る欄の上の枠に「Claude Code にログインしていません」 | ターミナルで `claude` を起動し、`/login` でログインしてから、Studio を起動し直す。Studio はログインの情報を扱わない |
| 試作品に「この試作品はプロダクト内 AI を使っていません」 | `app/ai.json` を置いて「作り直す」を押す([configuration.md の「プロダクト内 AI の設定」](configuration.md#プロダクト内-ai-の設定appaijson)) |
| 試作品に「会話が長くなりすぎました」 | 「リセット」を押す(1 つの会話は 200 件まで) |
| 「接続を選ぶ」で Claude Code を選べず「本物の AI は、使わない設定で起動されています」 | `STUDIO_ALLOW_CLAUDE_CODE=0` で起動されている。会社として止めているときは、そのままモックで試す。止める理由がなければ、この変数を書かずに起動し直す |
| 「本物の AI を使うことへの同意が要ります」 | 作る欄なら「同意して送る」、「接続を選ぶ」なら確認に印を付けて切り替える。同意は Studio を止めるまで有効で、起動し直すと消える([claude-code.md](claude-code.md#本物の-ai-を使う前の同意)) |
| 「Claude Code が見つかりません」 | Claude Code を入れる。入れた場所が PATH にないときは、`STUDIO_CLAUDE_BIN` に実行ファイルの場所を指定する |
| 「Claude Code にログインできていません」 | ターミナルで `claude` を起動してログインしてから、もう一度送る |
| 「Claude Code の利用の上限に当たりました」 | 時間をおいて送り直すか、「接続を選ぶ」でモックに戻す。会話は変わらない |
| 「1 回の呼び出しの費用の上限に当たった」 | 指示や会話を短くするか、リセットしてから送る |
| 「Claude Code への発言は、1 つの会話で 30 回までです」 | 「リセット」で最初からやり直すか、モックに戻す |
| 「90 秒で応答しなかったので止めました」 | もう一度送る。続くときは、モックに戻す |
| 「この試作品で実際の AI モデルを呼べるのは、観察も含めて 60 分に 120 回までです」 | 出ている分だけ待ってから送るか、モックに戻す。会話は変わらない |
| 「1 ターンで実際の AI モデルを呼べるのは 4 回まで」 | もう一度送る。続くときは、モックに戻して、記録を開発の担当者に見せる |
| 「試し直せませんでした: 試し直す会話がありません」 | AI の設定を変える前に、試作品で AI と話しておく。話していない会話は覚えない |
| 「試し直しが途中で止まりました」 | 理由を読み、必要なら「前の発言で試し直す」をもう一度押す。そこまでの結果は「試し直しの結果」に残る |
| 作る会話に「ビルドに失敗したので、プロダクト内 AI は前の設定のままです」 | 右の「詳細」で `app/ai.json` の誤りの場所を確かめ、直す依頼を送る |
| 版の欄に「ビルドできない状態は保存できません」 | 右の「ビルド」に出ている場所を直すか、作る欄で直す依頼を送ってから保存する |
| 版の欄に「保存できる版は 100 個までです」 | Studio を止めて、要らない版のフォルダー(`.studio/versions/<版の ID>`)を消す |
| 版の欄に「app/ が大きすぎるので版にできません」 | `app/` の要らないファイルを消す(500 個、1 ファイル 1 MB、合計 5 MB まで) |
| 版の欄に「…大きすぎて版にできないので、… に移しました」 | 戻す前の作業中は、出ている場所に残っている。要るファイルだけ `app/` に写す |
| 版の欄に「保存した会話は今の AI の設定に合わないので…」 | 版の `version.json` が手で直されたなど。ファイルは戻っている。会話は最初から始める |
| 引き継ぎの欄に「秘密情報らしい文字列があるので、書き出しませんでした」 | 出ているファイルと行から、鍵やトークンを消してから書き出す。作る欄で消す依頼を送ってもよい |
| 引き継ぎの欄に「ビルドできない状態は書き出せません」 | 右の「ビルド」に出ている場所を直してから書き出す |
