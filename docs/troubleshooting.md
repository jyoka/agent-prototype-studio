# うまくいかないとき

画面かターミナルに出たものから、することを探してください。

| 出るもの | すること |
|---|---|
| ターミナルに「Node.js 22 以上が要ります」 | Node.js を入れ直す |
| ターミナルに「必要な部品が入っていません」 | `npm install` を実行してから `npm start` |
| 作る会話に「試作品を開いて確かめることはできませんでした。この PC には、試作品を開いて確かめるためのブラウザーが入っていません」と出る。依頼の「開発者向け: 操作の詳細」に「Playwright の Chromium が見つかりません」と出る(観察の結果は `unverified`) | Studio のフォルダーで `npm run install:chromium` を実行する(約 200 MB をダウンロードする)。観察器は Playwright の Chromium だけを使い、利用者の Chrome や Edge は使わない。`npm install` で Playwright の版が変わったときも、入れ直す |
| 作る会話に「試作品を開いて確かめるためのブラウザーを起動できませんでした」と出る。仕組みの引き出しに「Chromium を起動できませんでした」と出る | `npm run install:chromium` で入れ直す。続くときは、仕組みの引き出しの理由の括弧の中の文を確かめる |
| 観察の結果が「未確認」で、理由に「試作品のビルドを開けませんでした」 | 観察の間に作り直された。もう一度観察する |
| ターミナルに「ポート 4317 は使われています」 | 別のターミナルで Studio が動いていないか確かめる。他のアプリが使っているなら、番号を変えて起動する([configuration.md の「環境変数」](configuration.md#環境変数))。プレビュー用の 4318 は `STUDIO_PREVIEW_PORT` |
| 画面に「鍵がありません」「鍵が合いません」 | ターミナルに出た最新の URL(`#token=` を含む)を開き直す。起動し直すたびに鍵は変わる |
| 画面に「Studio が止まっています」 | `npm start` のターミナルが開いたままか確かめる。止めたなら、もう一度 `npm start` |
| 仕組みの引き出し(今の行の「仕組みを見る」)の「ビルド」に「ビルドに失敗しました」 | 出ているファイルと行を直し、「ファイルから作り直す」を押す。作る AI の欄で直す依頼を送ってもよい。`app/ai.json` の誤りも、ここに項目の場所つきで出る |
| 作る AI の欄に「送れませんでした: … 作業中です」 | 前の依頼が終わるか、「止める」を押すまで待つ。1 つの試作品で動く依頼は 1 つだけ |
| 作る AI の欄に「時間の上限(10 分)を超えたので止めました」 | 依頼を小さく分けて送る |
| 作る AI の欄に「Claude Code にログインしていないか…」 | ターミナルで `claude` を起動し、`/login` でログインしてから送り直す。Studio はログインの情報を扱わない |
| 作る AI の欄に「言葉で直すには、Claude Code が要ります」「Claude Code が古いので使えません」「この Claude Code は、Studio から使えません」 | Claude Code を入れる、または `claude update` で更新して、Studio を起動し直す。別の場所にあるときは `STUDIO_CLAUDE_BIN`。理由の文は、カードの中の「開発者向け: 確かめた結果」にある。Claude Code を使わずに試すときは `STUDIO_AGENT=fake` |
| 作る AI の欄に「Claude Code にログインしていません」 | ターミナルで `claude` を起動し、`/login` でログインしてから、Studio を起動し直す。Studio はログインの情報を扱わない |
| 試作品に「この試作品には、話せる AI がありません」 | `app/ai.json` を置いて「ファイルから作り直す」を押す([configuration.md の「プロダクト内 AI の設定」](configuration.md#プロダクト内-ai-の設定appaijson)) |
| 試作品に「会話が長くなりすぎました」 | 「会話を最初から」を押す(1 つの会話は 200 件まで) |
| 「▲ お試し ▾」で本物の AI を選べず「本物の AI は、使わない設定で起動されています」 | `STUDIO_ALLOW_CLAUDE_CODE=0` で起動されている。会社として止めているときは、そのままモックで試す。止める理由がなければ、この変数を書かずに起動し直す |
| 「本物の AI を使うことへの同意が要ります」 | 作る AI の欄の「確かめる」か、もう一度「送る」を押すと、「本物の AI を使う前に」のカードが出る。中身を確かめて「同意して使う」を押す。同意は Studio を止めるまで有効で、起動し直すと消える([claude-code.md](claude-code.md#本物の-ai-を使う前の同意)) |
| 「この PC で Claude Code が見つかりません」 | Claude Code を入れて、Studio を起動し直す。入れた場所が PATH にないときは、`STUDIO_CLAUDE_BIN` に実行ファイルの場所を指定する |
| 試作品に「Claude Code にログインしていません」 | ターミナルで `claude` を起動してログインしてから、もう一度送る |
| 「本物の AI の利用の上限に当たりました」 | 時間をおいて送り直すか、「▲ 本物 ▾」でお試しの AI に戻す。会話は変わらない |
| 「1 回の呼び出しの費用の上限に当たった」 | 指示や会話を短くするか、「会話を最初から」を押してから送る |
| 「本物の AI への発言は、1 つの会話で 30 回までです」 | 「会話を最初から」で最初からやり直すか、お試しの AI に戻す |
| 「90 秒で返事をしなかったので止めました」 | もう一度送る。続くときは、お試しの AI に戻す |
| 「この試作品で本物の AI を呼べるのは、自動の確かめも含めて 60 分に 120 回までです」 | 出ている分だけ待ってから送るか、お試しの AI に戻す。会話は変わらない |
| 「1 回の発言で本物の AI を呼べるのは 4 回まで」 | もう一度送る。続くときは、お試しの AI に戻して、記録を開発の担当者に見せる |
| 「試し直せませんでした: 試し直す会話がありません」 | AI の設定を変える前に、試作品で AI と話しておく。話していない会話は覚えない |
| 「試し直しが途中で止まりました」 | 理由を読み、必要なら「もう一度試し直す」を押す。そこまでの結果は、試し直しの帯の「直す前と後の返事」に残る |
| 作る会話に「試作品を表示できないので、試作品の中の AI は前の設定のままです」 | 仕組みの引き出し(今の行の「仕組みを見る」)で `app/ai.json` の誤りの場所を確かめ、直す依頼を送る |
| 作る会話に「試作品のフォルダーの外は触れないので、やめました」 | 作る AI は試作品のフォルダー(`app/`)の外を読み書きできない(ADR 0001)。試作品の中で済む依頼に言い換えて送る。断られた操作と場所は、その依頼の「開発者向け: 操作の詳細」にある |
| 作る会話に「作る AI が 2 回直そうとしましたが、…の問題が残っています」 | 結果の帯の「確かめた中身を見る」で問題を確かめ、直したいことを言葉で送る。関門の名前とファイルの名前は、その依頼の「開発者向け: 操作の詳細」にある |
| 試作品の名前のメニューの「保存した状態」に「表示できない状態は保存できません」 | 作る AI の欄で直す依頼を送ってから保存する。誤りの場所は仕組みの引き出しの「ビルド」とターミナルに出る |
| 版の欄に「保存できるのは 100 個までです」 | Studio を止めて、要らない版のフォルダー(`.studio/versions/<版の ID>`)を消す |
| 版の欄に「試作品のファイルが大きすぎるので保存できません」 | `app/` の要らないファイルを消す(500 個、1 ファイル 1 MB、合計 5 MB まで) |
| 版の欄に「…大きすぎて版にできないので、… に移しました」 | 戻す前の作業中は、出ている場所に残っている。要るファイルだけ `app/` に写す |
| 版の欄に「保存した会話は今の AI の設定に合わないので…」 | 版の `version.json` が手で直されたなど。ファイルは戻っている。会話は最初から始める |
| 引き継ぎの欄に「秘密情報らしい文字列があるので、書き出しませんでした」 | 出ているファイルと行から、鍵やトークンを消してから書き出す。作る AI の欄で消す依頼を送ってもよい |
| 段の道筋の「9 渡す」の「本番開発へ渡す」に「表示できない状態は、本番開発へ渡せません」 | 作る AI の欄で直してもらってから書き出す。誤りの場所は仕組みの引き出しの「ビルド」とターミナルに出る |
