# 人の確かめの手順書(P31)

初めて Studio を見る非エンジニア 3 人に、「5 秒の確かめ」と「1 人で通す確かめ」を行うための手順です。
確かめ方の決まりは [ux-redesign.md の 9 節](../../../design/ux-redesign.md#人で確かめる最後のカードの受け入れ条件)にあります。
この手順書は、そのまま印刷するか画面に出して使えます。

## 合格の基準

| 確かめ | 合格 |
|---|---|
| 5 秒の確かめ | 3 人のうち 2 人以上が、2 つの問いの両方に「近い答え」を言える |
| 1 人で通す | 3 分以内に、口頭の助けなしで、3 番(直った結果を試す)まで終わる |

## 用意するもの

- 参加者 3 人。初めて Studio を見る人で、エンジニアではない人
- 5 秒の確かめで見せる画像: [U10-01-first.png](U10-01-first.png)(最初の画面。1440x900)
- 1 人で通す確かめに使う PC。Studio を起動したブラウザーを、画面いっぱいに出す
- 時計(3 分を計る)と、この手順書の記録の欄

### 1 人で通す確かめの Studio の起動

参加者ごとに、新しいデータの置き場で起動し直します。前の人が直した試作品と、案内の進み方を残さないためです。

```sh
STUDIO_HOME="$(mktemp -d)" npm start
```

- この起動では、直す AI に手元の Claude Code(本物の AI)を使います。参加者が「本物の AI を使う前に」のカードで同意すると、頼んだ文と試作品のファイルが Anthropic に送られ、Claude のプランの利用枠か料金を使います。架空のデータだけを使います
- 料金をかけたくないときは、`STUDIO_AGENT=fake STUDIO_HOME="$(mktemp -d)" npm start` で起動します。直す AI が決まった動きの偽物になります。ただし、上の帯に「開発用: 偽の直す AI」の印が出て、同意のカードは出ません。どちらで行ったかを記録の欄に書いてください
- 偽物の直す AI が直せるのは、右の「言葉で直す」の例(「時給の下限を先に聞くようにして」など)のような決まった依頼だけです。参加者が自由な文で頼んで何も変わらなかったときは、つまずいた場所として記録します

## 5 秒の確かめ

1 人ずつ行います。ほかの参加者には聞こえないところで行います。

1. 参加者に言う: 「これから画面を 5 秒だけ見せます。見た後に 2 つ質問します。」
2. [U10-01-first.png](U10-01-first.png) を画面いっぱいに出し、5 秒数えて隠す
3. 問い 1 を聞く: 「何をする画面ですか」
4. 問い 2 を聞く: 「最初に何をしますか」
5. 答えた言葉を、そのまま記録の欄に書く。言い直しや補足はしない

答えが「近い」かの目安:

| 問い | 近い答え | 近くない答えの例 |
|---|---|---|
| 何をする画面ですか | 「試作品を試して、言葉で直す」に近い。例: 「アプリを試して、気になるところを頼んで直してもらう」 | 「求人を探すサイト」だけ(直すことに触れない)、「AI を作る画面」 |
| 最初に何をしますか | 「試作品の中で AI に話しかける」に近い。例: 「左の欄に希望を書いて送る」 | 「右の依頼の欄に書く」「その他を押す」「分からない」 |

## 1 人で通す確かめ

5 秒の確かめの後、同じ人に続けて行います。

1. Studio を上の起動のしかたで開き、最初の画面を出しておく
2. 参加者に、次の文をそのまま読み上げる(紙に書いて渡してもよい)

   > これは、作りかけのアプリを試して、気になるところを言葉で頼んで直してもらう道具です。
   > 画面の案内に沿って、「試す」「言葉で直す」「直った結果を試す」の 3 つをやってみてください。
   > 3 分を計ります。私からは何も助けません。困ったら、思ったことを声に出してください。

3. 読み終えたら、時計を始める
4. 口頭の助けはしない。聞かれても「画面を見て進めてください」とだけ答える
5. 見ているだけで、次のことを記録する
   - つまずいた場所(どこで手が止まったか、何を探したか、何を押し間違えたか)
   - 声に出した言葉
6. 終わりの印が出たら、時計を止めて時間を書く。終わりの印は、試作品の上の「直す前と後の返事」が出て、上の案内の 3 つの手順に全部チェックが付いたこと。図書室など AI のない試作品を選んだときは、直った画面を触って 3 つの手順に全部チェックが付いたこと
7. 3 分を超えたら、そこで止める。どこまで進んだか(1 番、2 番、3 番)を書く

### 「本物の AI を使う前に」のカードが出たとき

同意するかどうかも、参加者に任せます。「やめる」を押して進めなくなったら、つまずいた場所として記録します。
直す AI(本物)が終わるまでの時間は、手元の Claude Code の速さで変わります。待った時間も記録してください(推測: 1 分前後かかることがあり、3 分の大半を使うことがある)。

## 結果の渡し方

タスク(jyoka/tasks#353)にコメントで、上の 2 つの表を貼ってください。表のまま貼れないときは、参加者ごとに次の形で書きます。

```
A: 問い 1「…」(近い/近くない)、問い 2「…」(近い/近くない)、通す: 2 分 40 秒、3 番まで、助けなし、つまずいた場所: …
```

再実行で、エージェントが結果を Report に書き、下のエージェントの代わりの答えと並べます。合わなかった所は、直すカードの案(タイトルと 1 行の中身)にします。

P31 の回でエージェントが挙げた、分からなかったところ:

- 「AI: お試し」で何が選べるのか。「決まった言葉だけ分かります」がどこまで通じるのか
- 「直す」が 2 か所ある(試作品の中の「希望条件」の「直す」と、右の「言葉で直す」)
- 「送る」が左右に 1 つずつある
- 右の「求人相談への依頼」が青い文字で、リンクに見える
- 「案内役」が何か、すぐには分からない

ほかの場面のカードの答え(同意のカード、結果の帯、使えないときのカード)は、各カードの PR の Report にあります: P23(PR #44)、P25(PR #47)、P26(PR #50)、P27(PR #52)、P30(PR #65)。
