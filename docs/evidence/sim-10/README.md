# sim-10 の実機: 模擬の会話の記録と、構成と前提の選び方

見本「バイト探し(架空・AI と話せる)」をお試しの AI(モックの模擬のエージェント)で開き、その他 → 開発者向けの詳細を撮った画面です。2026-10-29 に撮りました。実モデルは呼んでいません。

- 起動: `STUDIO_AGENT=fake` で Studio を起動し、新しい置き場(`STUDIO_HOME` は一時フォルダー)で開いた。画面の幅は 1440
- 操作: 「詳しく見せて」→「そのまま保存して」と送り、開発者向けの詳細を開いた。次に「前提を選ぶ」で `partner-b` を選び、もう一度「詳しく見せて」と送った
- 記録の 1 件だけを撮るときは、撮るためだけに、記録の一覧の高さの上限(`max-height`)を外した。画面の CSP は変えていない
- データと相手の仕様は、どれも架空
