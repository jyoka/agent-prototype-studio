Prototype Studio

AI エージェントの試作品を、作る前に、構成ごと手元で試して測る。Try and measure an AI agent prototype, whole setup included, on your machine before you build it.

構成とは、誰が会話を回し、誰がどのツールを持ち、守りをどこに置くかです。A setup is who runs the conversation, who owns which tools, and where the guardrails sit.

言葉で試作品を直し、模擬のエージェントと話し、場面を回して比べます。Edit the prototype in plain words, talk to a simulated agent, and run evals to compare setups.

試すのはモックで、料金はかかりません。本物の AI は、画面で同意したときと、--real で場面を回すときだけ使います。Trying runs on a mock and costs nothing. The real model runs only when you consent on screen, or when you run evals with --real.

できることWhat it does

絵は Studio が自分で撮った画面です。押すと、その機能の docs が開きます。The images are screens Studio took of itself. Click one to open the docs for that feature.

  • 言葉で直す欄Plain-word edits

    画面も AI の振る舞い(app/ai.json)も、欄に書いた依頼で変わる。Type a request to change the screens or the AI's behavior (app/ai.json).

    作る AI が書けるのは、試作品の app/ だけ。The maker AI can write only to the prototype's app/.

  • 構成の模擬Simulated setups

    相手のエージェント、こちらのツール、人への引き継ぎを app/composition.json に書く。Write the partner's agent, your tools, and handoffs to people in app/composition.json.

    模擬のエージェントが、ツールを自分で選んで呼ぶ。A simulated agent picks and calls the tools itself.

  • 守りの層Guardrail layers

    ツールの守り、プロンプトの頼み、出口の確かめの 3 つの層に分けて書く。Write guardrails in three layers: tool guards, prompt asks, and output checks.

    実行の記録に、どの層が止めたかと理由が出る。The trace shows which layer stopped a turn, and why.

  • 場面の比較Eval runs

    app/evals/ の場面を、構成と前提を替えて回す(npm run evals)。Run the evals in app/evals/ across setups and assumptions (npm run evals).

    自然さ、ツールの呼び方、守り、費用と待ち時間を並べて比べる。Compare naturalness, tool use, guardrails, and cost and latency side by side.

  • データだけの流用Data-only setups

    新しい構成は、構成、ツール、前提、プロンプトの JSON と文で足す。Add a setup with JSON and text files: composition, tools, assumptions, prompts.

    Studio のコードは変えない。ツールは探す、取る、記録するなどの決まった処理を組む。Studio's code stays the same. Tools combine fixed steps such as search, get, and record.

  • モックと実モデルMock and real model

    同じ試作品のまま、モックと Claude Code を切り替える。Switch the same prototype between a mock and Claude Code.

    モックはモデルを呼ばず、料金はかからない。実モデルは同意の後だけ。The mock calls no model and costs nothing. The real model runs only after you consent.

  • app/ → 版version → handoffs/

    版と引き継ぎVersions and handoff

    app/ のファイルと会話と状態を版として保存し、いつでも戻す。Save app/, conversations, and state as a version, and restore any of them.

    ソース、AI の設定、試した会話、証拠の要約を 1 つのフォルダーに書き出す。Export source, AI settings, tried conversations, and an evidence summary to one folder.

  • 検査 → ビルド → 場面 → 起動 → シナリオchecks → build → evals → launch → scenarios

    作るループの関門Build-loop gates

    作る AI が直すたびに、検査、ビルド、場面、起動、シナリオの関門を回す。After each edit by the maker AI, Studio runs gates: checks, build, evals, launch, and scenarios.

    落ちたら失敗を作る AI に返し、2 回まで直させる。On failure, it sends the result back to the maker AI for up to two fix rounds.

    npm install
